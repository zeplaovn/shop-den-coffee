# Đen Coffee - Management System

Welcome to the official repository of **Đen Coffee**. This project is a comprehensive web application designed to streamline coffee shop operations, from customer bookings to menu management and administrative control.

## ☕ About Đen Coffee
Đen Coffee is dedicated to providing a premium coffee experience. Our platform serves as a bridge between our passion for brewing and our customers, offering a seamless way to explore our offerings and secure a spot at our shop.

## 🛠️ Key Services & Features
The application provides a robust set of features for both customers and staff:

### For Customers
*   **Interactive Menu:** Browse our curated selection of coffees, specialty cakes, and diverse beverages.
*   **Wishlist System:** Save your favorite items to a personal wishlist for quick reference.
*   **Online Booking:** Easily book a table or register for our membership program.
*   **Responsive Design:** A polished, mobile-friendly interface for a smooth experience on any device.

### For Management (Admin & Manager)
*   **Dynamic Menu Management:** Admins can add, edit, or remove menu items, including prices and descriptions.
*   **Booking Oversight:** View and manage customer reservations in real-time.
*   **Automated Confirmations:** Streamlined process for confirming or canceling appointments.
*   **Role-Based Access:** Secure login system with distinct permissions for Administrators and Managers.

## 🚀 Tech Stack
*   **Backend:** Flask (Python)
*   **Database:** SQLAlchemy (SQLite/PostgreSQL)
*   **Frontend:** HTML5, CSS3, JavaScript
*   **Authentication:** Flask-Login & Bcrypt
*   **Form Handling:** Flask-WTF

## 🛠️ Installation & Setup
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/zeplaovn/shop-den-coffee.git
    cd shop-den-coffee
    ```
2.  **Create a virtual environment:**
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # On Windows: .venv\Scripts\activate
    ```
3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
4.  **Run the application:**
    ```bash
    python app.py
    ```
    The application will be available at `http://localhost:2005`.

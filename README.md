## About Đen Coffee

Welcome to the official repository of **Đen Coffee**. This project is a comprehensive web application designed to streamline coffee shop operations, from customer bookings to menu management and administrative oversight. Built with modern web technologies, Đen Coffee provides a seamless experience for both customers and staff.

Đen Coffee is dedicated to providing a premium coffee experience. Our platform serves as a bridge between our passion for brewing and our customers, offering a seamless way to explore our offerings, make reservations, and manage your preferences.

---

## Key Features & Services

### Customer Features
- **Interactive Menu:** Browse our curated selection of coffees, specialty cakes, and diverse beverages
- **Wishlist System:** Save your favorite items to a personal wishlist for quick reference
- **Online Booking:** Easily book a table or register for our membership program
- **Responsive Design:** A polished, mobile-friendly interface for smooth experience on any device

### Administrative Features
- **Dynamic Menu Management:** Add, edit, or remove menu items with prices and descriptions
- **Booking Management:** View and manage customer reservations in real-time
- **Automated Confirmations:** Streamlined process for confirming or canceling appointments
- **Role-Based Access Control:** Secure login system with distinct permissions for Administrators and Managers

## Installation & Setup

### Prerequisites
- Python 3.8 or higher
- pip package manager
- Git

### Steps

1. **Clone the Repository**
   ```bash
   git clone https://github.com/zeplaovn/shop-den-coffee.git
   cd shop-den-coffee
   ```

2. **Create Virtual Environment**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```

3. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run Application**
   ```bash
   python app.py
   ```
   The application will be available at `http://localhost:2005`
